# Frontend - Agricola Rancho Grande

Proyecto base del frontend para el Incremento 0.

## Scripts

- `npm run dev`: inicia el servidor de desarrollo.
- `npm run build`: genera la compilacion de produccion.
- `npm run preview`: sirve la compilacion generada.
- `npm run lint`: ejecuta Oxlint.

## Alcance actual

- React.
- Vite.
- Tailwind CSS.
- Pantalla tecnica inicial.

No incluye dashboard definitivo, autenticacion ni modulos de negocio.
