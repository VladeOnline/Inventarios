# Evidencias recomendadas - Incremento 0

Guardar capturas de:

- Estructura general del proyecto.

- Swagger visible en `/api/docs`.
- Solicitud `GET /api/health` en Postman.
- Resultado de pruebas automatizadas del backend.
- Resultado de validacion de Prisma.
- Resultado de compilacion del frontend.
