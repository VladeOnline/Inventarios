# Guia de Preguntas para Levantamiento de Requerimientos

Fecha sugerida de uso: 2026-10-02

Objetivo: confirmar procesos, datos, reglas y prioridades sin agregar funcionalidades fuera del anteproyecto aprobado.

## 1. Contexto operativo

- Como se administra actualmente el inventario?
- Que archivos, hojas de Excel o registros manuales utilizan hoy?
- Quien registra compras, entradas, salidas o cambios de inventario?
- Con que frecuencia se actualiza la informacion?
- Cuales son los errores o atrasos mas comunes del proceso actual?

## 2. Productos

- Que datos necesita guardar de cada producto?
- Usan codigos internos, codigos de barras o nombres comerciales?
- Los productos tienen presentaciones, unidades de medida o tamanos?
- Existen productos activos/inactivos?
- Hay productos con vencimiento o lote?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 3. Categorias

- Como clasifican actualmente los productos?
- Una categoria es suficiente o necesitan subcategorias?
- Las categorias se usan para buscar, reportar o tomar decisiones?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 4. Proveedores

- Que informacion debe registrarse de cada proveedor?
- Un producto puede tener uno o varios proveedores?
- Se necesita guardar historial de compras por proveedor?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 5. Inventario y existencias

- Como definen la existencia actual de un producto?
- Se permite que un producto quede con existencia negativa?
- Como manejan ajustes por error, perdida, dano o conteo fisico?
- Que significa para la empresa "inventario minimo"?
- Como se decide que un producto esta en bajo stock o agotado?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 6. Entradas y salidas

- Que tipos de entradas existen?
- Que tipos de salidas existen?
- Que datos deben registrarse en cada movimiento?
- Se necesita anular o corregir movimientos?
- Quien puede registrar movimientos?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 7. Costos, precios y utilidad

- Que costo debe guardarse: ultimo costo, costo promedio u otro?
- Como se define el precio de venta?
- Cambian los precios con frecuencia?
- Como desea calcular utilidad bruta?
- Desea conservar historial de costos y precios?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 8. Reportes

- Que reportes consulta actualmente?
- Que informacion necesita ver diariamente?
- Que informacion necesita ver semanal o mensualmente?
- Que filtros son importantes: fecha, producto, categoria, proveedor, movimiento?
- Necesita exportar reportes?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 9. Business Analytics

- Que indicadores considera mas importantes para tomar decisiones?
- Que graficos le serian utiles?
- Desea ver productos con bajo inventario, productos mas movidos, valor del inventario o utilidad?
- Que periodo de analisis necesita?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 10. Usuarios, seguridad y permisos

- Cuantas personas usaran el sistema?
- Todos los usuarios podran hacer lo mismo?
- Necesita roles o permisos diferentes?
- Que acciones deben quedar protegidas?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 11. Modo sin conexion

- En que situaciones espera usar el sistema sin Internet?
- Que informacion necesita consultar sin conexion?
- Que acciones necesita registrar sin conexion?
- Que debe pasar si dos registros se contradicen al sincronizar?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 12. Asistente hibrido

- Que preguntas frecuentes deberia responder el asistente offline?
- Que preguntas mas complejas espera hacer al asistente online?
- Que informacion no deberia responder el asistente?
- Esta dispuesto a usar un servicio/API de IA que podria tener costo?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.

## 13. Implementacion y pruebas

- Donde se probara la aplicacion?
- Que computadora o telefono usara el propietario?
- Quien validara que el sistema funciona correctamente?
- Que datos de prueba puede proporcionar la empresa?
- Que fecha o condicion marcaria una entrega aceptada?

Estado: PENDIENTE DE VALIDACION CON EL CLIENTE.
